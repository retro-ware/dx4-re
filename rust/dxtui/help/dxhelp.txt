=== Keyboard 2
   Alt-Space    opens window menu 1 'Sort' (also '1')
   Ctrl-Space   opens window menu 2 'Marks' (also '2')
   Shift-Space  opens window menu 3 'Directories' (also '3')
   The three menus are also reached with the mouse through the small
   yellow dots at the top left of each file window.

   '#'  shows the full name, owner and permissions of the cursor file
   '~'  removes all marks in the active panel

   On the command line:

   Ctrl-D       insert the cursor file name
   Ctrl-P       insert the directory of the active panel
   Ctrl-A       insert the directory of the other panel
   Ctrl-End     delete to the end of the line
   Up/Down      step through the command history
   Shift-Down   list the command history
   'cd DIR' changes the directory of the panel, 'exit' quits.
   The history keeps the last 25 commands.

   Further keys:

   Esc       cancels a function (mostly also the right mouse button)
   Space     quick search for a file name in the active panel
   Backspace command line with the last command
    +        mark files (with wildcards, e.g. *.sh;*.txt)
    -        unmark files
    *        invert the marks
   Ins       mark the cursor file and move down
   Del       unmark the cursor file and move down
   Tab       switch panels (also Left/Right)
   Shift-Up / Shift-Down mark while moving

 Point-and-shoot entries use %f for the file name, e.g. 'mpv %f'.
=== Working with the mouse
   Top of the screen:

     - Click on the top right corner: screen saver
       Right click there: shell screen (Alt-F5)
     - Click on the top left corner: quick menu
     - Click on a menu title: open the menu
     - Click on a path box: choose a place for that panel
       Right click on a path box: quick change directory

   Bottom of the screen:

     - Click on a function key label runs it.
       A right click switches the labels to Alt, Ctrl and Shift.
     - Click on the dot at the bottom left: quick menu
     - Click on the places bar: choose a place

   In the file windows:

     - Right click marks or unmarks a file
     - Double click starts a file or enters a directory
     - Dragging with the left button moves the cursor; at the top or
       bottom edge the list scrolls.
     - The dots at the top left open the window menus 1, 2 and 3,
       ▲ goes one directory up, ↨ rereads it and \ goes to the root.

   In general: a right click or a click outside a box cancels it.
=== The main screen and how files are shown
 The screen shows two file panels. The top line holds the menus and the
 clock, below each panel's path box comes its file window with name, size,
 date and time, the separator, and a status line for the cursor file or the
 sum of the marked files. Below the panels the places bar shows the root,
 the home directory and mounted volumes; the bottom line shows the function
 keys.

 The layout is that of the DOS version at 80x25 and grows with the
 terminal: wider terminals get longer names, taller ones more lines.

 Directories are listed first, files are sorted by extension (window
 menu 1 changes this). Programs (.sh .bat .exe ...) are shown in red,
 pictures in yellow; 'color.EXT = n' entries in dx.conf add colours,
 'file_colors = off' switches them off.

 Alt-3 and Alt-5 show the names in 3 or 5 columns, Alt-1 shows long names
 with their size, Alt-2 shows the start of the cursor file in the other
 panel (quickview).

=== User menu                                                            (F2)
 Here you start programs 'in a hurry'. The programs entered with
 'Admin' are started with the cursor keys, the mouse or the function keys.
 Clicking a button with the right mouse button lets you change the entry,
 enter a new one or move it.
 The menu item 'Separator' simply enters one of the offered characters
 (line - or asterisk * ...) as the name. This lets you arrange the
 buttons more clearly.

  Control: cursor keys, PgUp, PgDn, Tab and the mouse.
  Start  : Enter, the function keys or the mouse.
  F9     : opens the 'Admin' menu.
  Esc    : quits the user menu.
  Ctrl-Enter or a right click on one of the buttons opens the local
  menu of that button. Its functions explain themselves (New, Change,
  Delete, Exchange, Separator and Quit).

  The programs are divided into groups. A group is a menu item at the
  top of the screen. You set up the groups yourself (e.g. ~Tools
  ~Games ~Applications). Each group is a set of 21 buttons.
  The programs within a group are sorted with 'Entries: Sort' in the
  'Admin' menu. Double-click the program to move or highlight it with
  Enter, move it, and drop it again with a double click or Enter.


  Modify entries:
  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
  Insert, change and delete entries.
  With 'Insert' you choose a program in a 'small DX' (only programs
  and scripts are shown) and name it with Enter. The name is then
  inserted into the current group or set at the current position.

  [X] Directory change: when this option is on, the program is started
  in its own directory. Many programs need their home directory as the
  current directory, so this option is on by default.
  'Drive' (or Alt-F1/Alt-F2) changes to another place, such as your
  home directory or a mounted volume.


  Add a group:
  ▔▔▔▔▔▔▔▔▔▔▔▔
  Every group gets a hotkey, which you mark when naming the group:
  a tilde (~) before the letter. ~Games gives the hotkey G for this
  group, i.e. pressing 'g' shows this group of programs.

  The programs are started through the shell (sh -c), so command lines
  with arguments work.

  The entries are stored in the file dxmenu.txt in the DX directory
  (~/.config/dx).
=== Self-defined entries
 Shift-F1 starts the menu program dxm to edit the user menu.
=== Change attributes
 Sets the permissions of the cursor or marked files, either as an octal
 number (644, 755) or in chmod notation (u+x, go-w).
=== Change time and date
 Sets the time stamp of the cursor or marked files. Enter the time as
 YYYY-MM-DD hh:mm:ss; an empty field sets the current time.
=== Print
 This function belonged to the DOS version and is not available here.
=== View
 F3 shows the cursor file. The top line shows the keys and the size, the
 bottom line the name, the line number and the offset of the cursor with
 the byte under it.

   F1  Help        F2  Print (not available)
   F3  Copy the marked range to a file (NAME.cut by default)
   F5  Find again  F7  Find (case is ignored)
   F9  Offsets in hex or decimal
   Return  sets the start and then the end of the marked range
   Esc     ends
 Long lines are wrapped at the screen width.
=== Edit
 F4 edits the cursor file with the editor from the configuration, else
 $VISUAL, $EDITOR or vi. Alt-F4 asks for a name and edits a new file.
=== Hex editor
 F9 opens the cursor file in the hex editor: offset, 16 bytes in hex and
 as characters per line. Hex digits overwrite the byte under the cursor,
 Tab switches to the character column where typed characters are stored.
 Changed bytes are shown in white. F2 saves, Esc ends and asks whether to
 save the changes.
=== Synchronize directories
 Copies the files of the active panel that are missing or older in the
 other panel's directory there.
=== Find duplicate files
 Looks for files with equal contents below the directory of the active
 panel. Return on a file goes there.
=== Find files
 Searches the directory tree of the active panel for names matching one
 or more wildcards (*.txt;*.md). Return on a result goes to the file.
 Esc stops a long search.
=== Find text in selected files
 Searches the marked files (or all files of the panel) for a text,
 ignoring case. The results show file, line number and line; Return
 opens the file in the viewer.
=== Compare directories
 Marks the files that are missing in the other panel, differ in size or
 are newer, in both panels.
=== QCD quick directory change
 Enter a part of a directory name; DX goes there, or lists the matches.
 The directory tree of your home directory is read once and kept in
 qcd.txt; enter '!' to read it again.
=== Split
 Splits the cursor file into parts of a given size (k and m allowed),
 written as NAME.001, NAME.002, ... to the other panel's directory.
=== Join
 Joins the marked files (or NAME.001, NAME.002, ... when the cursor is
 on the first part) into one file in the other panel's directory.
=== Send and receive files
 This function belonged to the DOS version and is not available here.
=== Directory sizes
 Adds up the sizes of all directories in the active panel and lists them,
 largest first. Esc stops.
=== Drive overview
 Lists the places (root, home, mounted volumes) with their free and
 total space. Return goes there.
=== Drive statistics
 Shows total, used and free space of the file system of the active
 panel.
=== Disk operations
 This function belonged to the DOS version and is not available here.
=== Calculator + hex-dec-bin converter
 Calculator (Alt-R): + - * / % ^ and parentheses. Numbers may be written
 decimal (123), hexadecimal ($7B, 7Bh, 0x7B), binary (1111011b) or as a
 character ('A'). Whole results are shown in all bases.

 Hex-dec-bin (Alt-H) shows a number in all bases.
=== ASCII table
 Shows the 256 characters of code page 437. The arrows move, a typed
 key jumps to its character; the bottom line shows the codes.
=== Quick menu
 A list of the tools: calculator, ASCII table, calendar, stopwatches,
 notes, history, find, and more.
=== Notes, time, date

 Alt-Z shows the time and date.
=== Command line history

=== Point-and-shoot
 Return on a file with a registered extension runs its command, e.g.

=== Quickview on/off
 Alt-2 shows the start of the cursor file (or the contents of the

=== Long names on/off

=== 1st window menu: sort + file filter
 Sort by name, extension, size, time or not at all, reverse the order,
 set a filter of wildcards (*.rs;*.toml) or show all files.
=== 2nd window menu: selection

=== 3rd window menu: change directory
 Up to 16 bookmarked directories; 'Add current directory' adds the
 panel's directory, 'Remove' removes it, a letter goes there.
=== Tips and general notes
 - Settings and data live in ~/.config/dx (or $DX_HOME): dx.conf,
   dxhist.txt (command history), qcd.txt, notes.txt, dxmenu.txt.
 - Commands run in the active panel's directory with your $SHELL.
 - The screen follows the terminal size; 80x25 looks like the original.
=== Input screens
 In all input fields:
   Ins       switches between insert and overwrite
   Return    ends the input
   Esc, F10  cancel; the old contents stay
   A right click cancels as well.
=== Copying with DX
 F5 copies the cursor or marked files to the directory shown (by default
 the other panel's). Directories are copied with everything in them,
 time stamps and permissions are kept, links stay links. When a file
 exists, DX asks: Yes, All, Skip, None or Cancel.
 F6 renames or moves; across file systems it copies and deletes.
 Esc stops a running copy.
=== External programs
 The editor, the external viewer (less), zip/unzip, tar, 7z and touch
 are started as needed.
=== The menu program dxm
  DXM stands for DX menu. It is the user menu as a program of its own;
  the main program shows the same menu on F2.

  Choose a program and DXM runs it; when the program ends, the menu
  comes back. Esc or 'Quit' ends DXM.

  The screen saver of DXM uses the settings of DX (dx.conf): the delay
  and the password.
