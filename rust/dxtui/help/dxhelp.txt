=== User menu                                                            (F2)
 Here you start programs 'in a hurry'. The programs entered with
 'Admin' are started with the cursor keys, the mouse or the function keys.
 Clicking a button with the right mouse button lets you change the entry,
 enter a new one or move it.
 The menu item 'Separator' simply enters one of the offered characters
 (line - or asterisk * ...) as the name. This lets you arrange the
 buttons more clearly.

  Control: cursor keys, PgUp, PgDn, Tab and the mouse.
  Start  : Enter, the function keys or the mouse.
  F9     : opens the 'Admin' menu.
  Esc    : quits the user menu.
  Ctrl-Enter or a right click on one of the buttons opens the local
  menu of that button. Its functions explain themselves (New, Change,
  Delete, Exchange, Separator and Quit).

  The programs are divided into groups. A group is a menu item at the
  top of the screen. You set up the groups yourself (e.g. ~Tools
  ~Games ~Applications). Each group is a set of 21 buttons.
  The programs within a group are sorted with 'Entries: Sort' in the
  'Admin' menu. Double-click the program to move or highlight it with
  Enter, move it, and drop it again with a double click or Enter.


  Modify entries:
  ▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔
  Insert, change and delete entries.
  With 'Insert' you choose a program in a 'small DX' (only programs
  and scripts are shown) and name it with Enter. The name is then
  inserted into the current group or set at the current position.

  [X] Directory change: when this option is on, the program is started
  in its own directory. Many programs need their home directory as the
  current directory, so this option is on by default.
  'Drive' (or Alt-F1/Alt-F2) changes to another place, such as your
  home directory or a mounted volume.


  Add a group:
  ▔▔▔▔▔▔▔▔▔▔▔▔
  Every group gets a hotkey, which you mark when naming the group:
  a tilde (~) before the letter. ~Games gives the hotkey G for this
  group, i.e. pressing 'g' shows this group of programs.

  The programs are started through the shell (sh -c), so command lines
  with arguments work.

  The entries are stored in the file dxmenu.txt in the DX directory
  (~/.config/dx).

=== The menu program dxm
  DXM stands for DX menu. It is the user menu as a program of its own;
  the main program shows the same menu on F2.

  Choose a program and DXM runs it; when the program ends, the menu
  comes back. Esc or 'Quit' ends DXM.

  The screen saver of DXM uses the settings of DX (dx.conf): the delay
  and the password.
